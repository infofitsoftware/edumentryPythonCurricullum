# Edumentry Python Curriculum — AI-Era Design Principles

This curriculum prepares beginners for a world where **AI assistants draft code**, but **humans own correctness**.

## North Star

Students should leave confident enough to:

1. Write fundamentals without fear  
2. Trace and predict program output  
3. Debug their own mistakes and AI mistakes  
4. Explain concepts in interviews  
5. Connect each idea to real systems (FastAPI, AI pipelines, automation)

## Teaching Pattern (Every Module)

```
WHY (career/AI context)
→ WHAT (concept)
→ SYNTAX
→ TRACE
→ REAL-WORLD PREVIEW (API / AI / automation)
→ COMMON MISTAKES
→ EXERCISES
→ QUIZ
```

## Sequential Path

| # | Module | Confidence unlock |
|---|--------|-------------------|
| 1 | Intro + Basic Operations | Run, print, input, arithmetic, verify |
| 2 | Variables & Types | Cast, validate, avoid type bugs |
| 3 | Strings | Prompts, parsing, cleaning |
| 4 | Operators | Rules & conditions |
| 5 | Control Flow | Decisions & loops |
| 6 | Collections | Structured data |
| 7 | Functions | Reusable logic |
| 8 | File Handling | Persistence |
| 9 | Important Modules | stdlib power tools |
| 10 | Classes & Objects | Model real entities |

## AI / Vibe Coding Policy

- AI tools (Cursor, ChatGPT, etc.) are encouraged as **accelerators**
- Students must still **trace, run, and explain** every solution they submit
- Interview readiness > prompt-only productivity

## Real-World Previews (Not Premature Framework Teaching)

In early modules we show **where** a concept appears in FastAPI/AI, without requiring those frameworks yet.

Example (Module 1):
- `print` → logs  
- `input` → request/prompt text  
- `//` `%` → batching & pagination  
- `*` → token cost estimates
